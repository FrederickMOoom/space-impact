# 🚀 Space Impact: Cute Alien Adventure! 👾✨

Game petualangan aksi luar angkasa bergaya kartun yang seru, penuh warna ceria, ramah anak (*family-friendly*), dan beranimasi mulus (*smooth*). Terinspirasi dari game klasik *Space Impact*, kini dengan visual modern yang menggemaskan!

## 🌟 Fitur Utama

- **🎨 Grafis Kartun Ceria & Ramah Anak**: Latar belakang antariksa bergradien ungu-biru dengan planet bercincin kartun dan 40+ bintang warna-warni yang berkelap-kelip dinamis.
- **👾 Monster Alien Luar Angkasa yang Imut**:
  - 🟢 **Blobby**: Monster jeli hijau mint membal dengan mata siklop kartun besar yang melirik pemain.
  - 🌸 **Octo-Puff**: Alien gurita/ubur-ubur merah muda pastel yang melayang anggun dengan gerakan gelombang sinus (*sine wave*).
  - 🟠 **Chompy-Horn**: Monster bulat oranye bertanduk ungu dengan mulut yang membuka-menutup menggemaskan.
  - 👑 **Boss Raja Bloop (Level 5)**: Monster jeli raksasa bermahkota emas dengan 3 mata kartun.
  - 🌌 **Kaisar Kosmik Tentaking (Level 10)**: Monster naga kosmik legendaris dengan tanduk emas bercahaya dan tembakan kristal spektakuler.
- **🛒 Toko Pesawat (Ship Hangar Shop)**:
  - 🐱 **Astro-Cat**: Roket putih-toska dengan pilot kucing astronot.
  - 🐰 **Candy-Bunny**: Pesawat stroberi membal merah muda dengan pilot kelinci bertelinga panjang (*50 🪙*).
  - 🐶 **Puppy-Hero**: Piring terbang emas tangguh dengan pilot anak anjing berkacamata penerbang (*100 🪙*).
  - 🦖 **Dino-Jet**: Jet aerodinamis bersayap naga hijau dengan pilot dino ceria (*200 🪙*).
  - 🛸 **Cosmic-UFO**: Piring terbang kosmik pelangi dengan pilot alien ramah bermata satu (*350 🪙*).
- **🪙 Sistem Koin Permanen**: Koin emas disimpan secara otomatis di peramban (*localStorage*).
- **⏸️ Menu Jeda Dalam Game (In-Game Menu)**: Tombol jeda di bar atas atau tombol `Escape` / `P` untuk menjeda, berganti pesawat di toko, mengulang, atau kembali ke menu utama.
- **🎵 Efek Suara Kartun Terintegrasi**: Dihasilkan langsung melalui browser menggunakan Web Audio API tanpa file audio eksternal.
- **📱 Kontrol Responsif**: Mendukung Keyboard (Panah / WASD + Spasi) serta kontrol tombol sentuh (*D-Pad Touch*) untuk HP/Tablet.

## 🎮 Cara Bermain

1. Buka file `index.html` di browser apa saja (Chrome, Edge, Firefox, Safari).
2. Pilih tingkat kesulitan: **🌟 Santai**, **⚡ Normal**, atau **🔥 Tantangan**.
3. Pilih mode terbang: **🚀 Solo** atau **🤖 + Pet Drone**.
4. Gunakan tombol keyboard:
   - **Panah / W, A, S, D**: Mengendalikan arah terbang pesawat.
   - **Spasi**: Menembak bintang laser.
   - **Escape / P**: Menjeda game dan membuka menu.
5. Atau gunakan tombol sentuh di layar jika bermain lewat smartphone/tablet.
